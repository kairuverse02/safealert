SafeAlert: Web-Based Human Monitoring System with Perimeter Detection
Overview
SafeAlert is a modern monitoring solution designed to provide affordable and effective surveillance with advanced features. Unlike traditional and expensive CCTV systems that often lack smart functionalities, SafeAlert offers live streaming, automated perimeter alerts, and real-time notifications via push, SMS, and email.

This project addresses the limitations of current monitoring solutions by providing a system that is accessible and responsive to the needs of guardians and users.

Key Features
Live Streaming: Access a real-time video feed from anywhere on your smartphone, ensuring you can monitor your space at all times.

Perimeter Detection: Define virtual perimeters for specific areas. The system automatically triggers an alert if the perimeter is breached, providing an immediate and reliable notification of potential security issues.

Real-time Notifications: Receive instant alerts through multiple channels—push notifications, SMS, and email—ensuring you never miss a critical event.

Snooze Functionality: Guardians have the ability to snooze unnecessary alerts, reducing notification fatigue and allowing for a more customized monitoring experience.

Walkie-Talkie Communication: The system includes a walkie-talkie feature (if supported by the hardware), enabling two-way communication with the monitored space.
